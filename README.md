## このModについて

このModは **SwordSkill** に新たな武器種を追加するModです。

追加される武器種は以下の7種類です。

- 大剣
- メイス
- レイピア
- 短剣
- 刀
- 爪
- 鎌

各武器種について、石・鉄・金・ダイヤモンド・ネザライトの5段階の素材が用意されています。

武器ごとのモデル・テクスチャ・クラフトレシピ・アイテムタグが含まれます。

## 動作環境

Minecraft 1.21.1 / NeoForge 21.1.x (Java 21)。

1.20.1 Forge 版から移植したものです。SwordSkill 側の武器判定がデータパック方式になったため、
`data/swordskill/weapon_types/` に各武器種の定義を追加しています（SwordSkill は任意依存）。
