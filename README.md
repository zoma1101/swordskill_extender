## このModについて

このModは **SwordSkill** に新たな要素を追加するModです。  
具体的には、以下のような各種素材の武器を追加しています。

- 片手剣
- 斧
- 槍
- 二刀流武器
- 刀
- レイピア
- 短剣
- 鎌
- 爪
- 大剣
- メイス

また、SwordSkillに**熟練度（プロフィシェンシー）システム**を追加し、武器を使い込むことで成長できる仕組みを導入しています。

---

## 予定されている要素

- 各武器種ごとに複数体のボスを追加
- 各種ソードスキルを解放するための巻物の追加  
  （構想が固まり次第、元のSwordSkill Modにも追加予定）
- ソードスキルへの属性付与
- 熟練度を上げるための本と、それに対応したダンジョンの追加
- スキルオーブの用途・仕様変更
- そのほか多数の要素を追加予定

---

## 別Modとしている理由

本Mod（**Zoma's SwordSkill**）は、より大きな変更や拡張要素を追加することを目的として分離されています。  
これらの要素をすべて元のSwordSkillに含めてしまうと、  
「ソードスキルをシンプルに使いたい」プレイヤーにとって扱いづらくなると考えたためです。

そのため、大型・実験的な要素については本Mod側で更新・開発を行っていく予定です。
